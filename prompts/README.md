# Biblioteca de Prompts

Prompts são aceleradores, não fontes de verdade. Antes do uso, remova dados sensíveis, forneça contexto suficiente e defina o formato da resposta. Toda saída relevante deve passar por revisão humana e pelos padrões aplicáveis.

## Catálogo

- `discovery-analysis.md`: sintetizar pesquisa e oportunidades.
- `architecture-review.md`: revisar uma proposta arquitetural.
- `quality-review.md`: identificar lacunas de teste e aceite.
- `delivery-handoff.md`: gerar um handoff verificável.

## Regras

1. Substitua todos os campos entre colchetes.
2. Cite as fontes internas fornecidas e marque inferências.
3. Peça perguntas quando dados críticos estiverem ausentes.
4. Nunca envie credenciais, dados pessoais ou conteúdo restrito a ferramentas não aprovadas.
5. Salve decisões no artefato oficial, não apenas na conversa com IA.
