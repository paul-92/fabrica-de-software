# Workflows

Fluxo padrão: `intake-discovery` → `definition-planning` → `delivery-quality` → `release-operations`. Cada transição exige as evidências do gate; projetos pequenos podem combinar reuniões, nunca omitir critérios.

| Fase | Dono | Gate |
|---|---|---|
| Intake/Discovery | Product + Delivery | problema e viabilidade |
| Definição/Planejamento | Product + Tech Lead | compromisso consciente |
| Entrega/Qualidade | Tech + Quality | release candidate |
| Release/Operação | Operações + Product | resultado e estabilidade |

Mudanças materiais seguem `change-control.md`.
