# Governança

## Direitos de decisão

Produto decide prioridade e aceite; Tech Lead decide implementação e arquitetura dentro dos guardrails; Security/Privacy pode bloquear risco inaceitável; Quality recomenda go/no-go; sponsor decide mudanças materiais de resultado, orçamento e prazo.

## Gates

| Gate | Evidência mínima |
|---|---|
| Oportunidade | brief, sponsor, resultado |
| Discovery | evidência, hipótese, recomendação |
| Kickoff | PRD, arquitetura, plano, riscos |
| Release candidate | DoD e evidências |
| Go-live | go/no-go, rollback, operação |
| Encerramento | aceite, handoff, métricas, retro |

## Exceções

Registrar padrão afetado, justificativa, impacto, compensações, aprovador, dono, validade e plano de remoção. Exceção expirada volta a bloquear a gate.

## Registros oficiais

PRD para produto; ADR para arquitetura; RAID para risco/decisão operacional; release record para publicação; postmortem para incidente. Conversas apontam para o registro, não o substituem.
